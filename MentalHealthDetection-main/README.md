# Mental Health Detection from Text

This project detects signs of depression or stress from text using a fine-tuned BERT model and Streamlit.

## Features
- Single text input prediction
- CSV batch prediction
- Download predictions as CSV
- Works with your own trained model

## Usage
1. Put your trained model files inside the `model/` folder.
2. Install dependencies: `pip install -r requirements.txt`
3. Run app: `streamlit run app.py`
4. Optionally deploy on [Streamlit Cloud](https://share.streamlit.io) or Hugging Face Spaces.
